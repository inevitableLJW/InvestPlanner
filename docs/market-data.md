# 市场数据组件与生产使用边界

本项目把开源组件许可与上游数据使用权分开管理。下列版本是本次变更核验并固定的采集运行时；升级前必须重新运行契约测试并更新本表。

| 项目 | 固定版本 | 代码许可 | 生产使用结论 |
| --- | --- | --- | --- |
| AKTools | `0.0.91` | MIT，部署镜像中保留许可证 | 只提供 HTTP 适配层；MIT 不授予任何上游数据权利 |
| AKShare | `1.18.64` | MIT，部署镜像中保留许可证 | 只提供接口实现；MIT 不授予东方财富、天天基金等数据的生产使用权 |
| 东方财富 / 天天基金公开接口 | 不适用 | 不适用 | 不存在由 MIT 自动授予的数据权利；本自托管部署由部署方确认条款并设置 `MARKET_DATA_PRODUCTION_APPROVED=true` 后常开采集 |
| Tushare Pro | 服务端 API | 依账户协议 | 必须由部署方提供合法 token 并确认所需积分及生产用途；未配置时禁用严格口径，改用明确标记的免费 QQQ/SPY 代理口径，代理序列也不足时才显示 `--` |
| 中国外汇交易中心 | 官方公开页面 | 不适用 | 仅保存并展示带来源地址和日期的规划参考值；部署方仍须确认其生产抓取与再展示条款，未确认时生产默认禁用 |

`hangliuc/qdii-fund-monitor` 与 `jomonylw/qdii-limit` 在核查时未发现明确许可证。本项目只参考公开接口行为、缓存/降级等通用架构思想；没有复制其代码、测试样本或表达。

所有外部信息都是参考数据，不参与月度记录的保存事务。未配置、未授权、字段口径不足或上游失败时返回 `--` 及安全原因，不用零值或推测值替代。

QDII 采集与助手没有运行时关闭开关。生产启动仍要求部署方显式设置 `MARKET_DATA_PRODUCTION_APPROVED=true`，该值只表示此部署的条款确认，不代表项目取得或转授任何上游数据许可证。
